# RootCause AI — demo script (2 minutes)

1. Open the command center and note the system-health overview.
2. Enter: “Investiga por qué las ventas están 38% por debajo de lo normal.”
3. Watch the agent inspect sales, detect the anomaly, and correlate the ETL error with duplicate records.
4. Review the root-cause and impact card.
5. Approve recovery; the agent isolates duplicates and reprocesses affected records.
6. Show the verification evidence and final **Incident Resolved** state.

This script is activated after phases 2–5 add the data, tools, agent, and UI workflow.
